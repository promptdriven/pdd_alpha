# Native local conversation launch

Own `src/native-session.mjs`; export `launchNativeSession({agent,cwd,context,request,selection,stderr},{spawn,signals,stdinIsTTY}) -> Promise<integer>`. `selection` is `null` or the validated `{model, effort}` pair that the CLI resolved from `--model`/`--effort` and the Settings defaults through [machine CLI models](workflow-models.prompt.md); this module passes it to `nativeArgs` unchanged and never chooses a model or effort itself. Codex and Claude both accept one initial positional prompt (official CLI references). Compose the full supplied guide/skill/refs/workflow context and optional person request into that single trusted-heading argument. Default agent selection belongs to the CLI catalog/parser. Spawn only installed `codex` or `claude` by name with argv array, unchanged environment/cwd and inherited stdio, no shell. Do not use private wrapper paths, auth repair/config rewrite, credentials, developer/config overrides, replacement system instructions, any model or effort other than the validated `selection`, or any flags beyond the full-access launch mode below.

Wait for actual child close, preserve its integer exit code, map signal exits to128+OS signal, and remove temporary signal listeners. Missing native returns127 with an actionable diagnostic; other launch failure returns1. No install/fallback/retry. SIGTERM/SIGHUP directed to the wrapper forward to its child; a non-TTY SIGINT also forwards. With inherited interactive foreground terminal, SIGINT already reaches the native process group and is not duplicated by the wrapper; keep waiting for native to close. Tests must prove argv/context/cwd/inherited stdio, exact user text including metacharacters, exit/missing behavior, forwarded directed signals and no duplicate interactive SIGINT. No real model calls in source controls.

## Full-access native launch

Start native agents in full-access mode without approval prompts. Native arguments are exactly `nativeArgs({agent, cwd: <resolved absolute cwd>, selection})` from [native launch flags](native-flags.prompt.md), followed by the one composed context/request element. That module owns the Codex no-daemon, bypass and per-invocation exact-cwd trust elements and the Claude flag; add, remove or reorder no flag here. Folder trust applies only to this invocation; do not write a trust entry to disk. Do not write global native configuration, change auth/provider or environment, change the model or effort outside the validated `selection`, add arbitrary CLI passthrough or remove these flags after a refusal. Keep ordinary cwd, guide-before-Story and existing close/exit/signal/127 behavior. Native initial consent or root refusal remains the real returned outcome, never autoanswer/retry/escalate to another mode. Foreground Codex uses its supported no-daemon route so incompatible shared-server settings cannot block this launch. Do not restart or reconfigure a shared server; preserve existing native login, provider, model and environment. Background stage transport is separately owned.
